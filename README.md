# pondu

| [assistant/](assistant/README.md) | 비서의 프롬프트·출력 형식·규칙 검사와 시험 세트 |
| `supabase/` | DB 마이그레이션, 서버 함수, 테스트(`supabase/tests/run.sh`) |

# 실기기 확인 (iPhone 한 대)

`PROGRESS.md`의 "실기기 확인 일정" 가운데 기기 한 대로 볼 수 있는 것을 순서대로 적었다.
기기를 손에 들고 해야 하는 일(촬영, 알림 누르기, 설정 바꾸기)은 사람이 하고, 설치와 서버 쪽 확인은 Mac의 에이전트가 한다.
결과는 `PROGRESS.md` 표에 `[실기기]`로 적는다. 기기 모델과 iOS 버전을 같이 적는다.

## 0. 설치 (Mac)

1. iPhone을 케이블로 Mac에 연결하고 "이 컴퓨터를 신뢰"를 누른다. iPhone 설정 → 개인정보 보호 및 보안 → 개발자 모드를 켠다(재시동).
2. Xcode에서 프로젝트를 열고 App 타깃의 Signing & Capabilities에서 Team을 본인 Apple 계정으로 고른다. Bundle Identifier는 `com.example.pondu` 대신 본인만 쓰는 값으로 바꾼다.
   - 이 두 값은 **커밋하지 않는다**(로컬 설정이다).
   - 무료 Apple 계정이면 앱이 7일 뒤 만료되고 원격 알림(APNs)은 쓸 수 없다. 아래 항목은 전부 무료 계정으로 가능하다.
3. 실행 대상을 연결한 iPhone으로 고르고 Run. 처음에는 iPhone 설정 → 일반 → VPN 및 기기 관리에서 개발자를 신뢰한다.
4. 기존 QA 계정으로 로그인한다.

## 1. 확인 항목

## 2. 이번에 하지 않는 것

- V1 추가 메일 2곳, 새 계정 가입: 다른 고려대 메일 주소가 필요하다.
- V9 친구·크루·같이 하기·차단: 기기 두 대와 계정 두 개가 필요하다.
- V10 피드 스크롤: 친구의 사진 기록이 여러 개 있어야 한다.
- 원격 알림(친구 반응 등): 유료 Apple 개발자 계정과 APNs 키가 필요하다.

# QA 지시문 — Mac에서 실행 중인 앱 점검

Mac에서 이 저장소 폴더로 Claude Code(또는 다른 에이전트) 세션을 열고 아래 "지시문"을 그대로 붙여 넣는다.
Codex가 같은 폴더에서 작업 중이면 겹치지 않도록 이 점검은 코드를 고치지 않는다.

---

## 지시문

이 Mac에서 iPhone 앱 "pondu"(대학생 실행 기록 앱)의 QA를 맡습니다. 앱은 이미 빌드되어 기기(시뮬레이터 또는 연결된 iPhone)에 열려 있습니다. 그 실행 중인 앱을 기준으로 점검하고 결과를 보고하는 것이 목표입니다.

### 하지 말 것

- 다른 에이전트가 같은 저장소에서 동시에 작업 중일 수 있습니다. 코드를 고치거나 git checkout, reset, stash, pull, commit, push를 하거나 빌드 산출물을 지우지 마세요. 코드는 읽기만 합니다.
- 앱을 지우거나 시뮬레이터를 초기화(erase)하지 마세요. 실행 중인 다른 앱이나 프로세스를 끄지 마세요.
- 실제 사람에게 메일이나 알림이 가는 동작(실제 주소로 인증 코드 발송 등)은 이미 설정된 테스트 계정이 있을 때만 하세요. 없으면 그 단계는 "확인 못 함"으로 남깁니다.
- 비밀 값(API 키, 관리자 키)을 출력하거나 보고에 적지 마세요.
- 화면을 누르지 못한 것을 눌러 봤다고 쓰지 마세요.

### 1. 상황 파악

- 실행 중인 기기: `xcrun simctl list devices booted`, `xcrun devicectl list devices`. 어느 쪽에 앱이 떠 있는지, 번들 ID가 무엇인지 확인합니다.
- 저장소 상태(읽기만): `git status -sb`, `git log --oneline -5`. 어떤 커밋 위에 어떤 미커밋 변경이 있는지 보고에 적습니다.
- 기준 문서: `AGENTS.md`, `docs/HANDOFF.md`, `PROGRESS.md`, `docs/specs/M0.md` 5.2절, `docs/PRD.md` 5~9절.

### 2. 점검

시뮬레이터라면 `xcrun simctl io booted screenshot <파일>`로 화면을 찍어 직접 보고, `xcrun simctl spawn booted log stream --predicate 'process == "<앱 프로세스>"' --level debug`(짧게)로 오류 로그를 확인합니다. 화면을 조작할 수단(접근성 자동화, XCUITest, UI 자동화 도구)이 있으면 쓰고, 없으면 조작 없이 볼 수 있는 범위(현재 화면, 로그, 실행·종료·재실행)까지만 하고 어디서 막혔는지 적습니다.

| # | 항목 | 볼 것 |
|---|---|---|
| 1 | 실행 | 앱이 뜨는가. 첫 화면이 무엇인가(설정 필요 안내, 메일 입력, 홈). 실행 후 첫 화면까지 걸린 시간 |
| 2 | 서버 연결 | Supabase 주소와 공개용 키가 설정돼 있는가(값은 적지 않고 설정 여부만). 실제로 연결되는가 |
| 3 | 가입 | 메일 입력 → 코드 입력 → 프로필 → 홈. 고려대가 아닌 주소의 거절 문구. 틀린 코드 |
| 4 | 유지 | 앱을 완전히 끄고 다시 켜면 바로 홈인가. 비행기 모드에서 켜면 어떻게 보이는가 |
| 5 | 로그아웃 | 메일 입력 화면으로 돌아가는가 |
| 6 | 탭 | 오늘, 함께, 기록이 뜨는가. 각 탭의 빈 상태와 오류 상태 |
| 7 | 세션 | 시작(사진 없는 기록) → 진행 중 막대 → 일시 정지·재개 → 종료 3택 → 기록 탭에 표시 |
| 8 | 세션 재전송 | 통신을 끊고 시작한 뒤 다시 연결하면 세션이 하나만 생기고 `오프라인 시작`으로 표시되는가 |
| 9 | 오늘 | 할 일 추가·완료, 예정 시간 만들기, 캘린더 권한 요청, `지금 시작`이 시작 화면을 여는가 |
| 10 | 비서 | 한 줄 입력, 하루 정리. 서버 함수가 없거나 실패하면 직접 입력으로 넘어가는가. 첫 사용 동의 화면 |
| 11 | 함께 | 친구가 없을 때 빈 화면, 아이디 검색, 크루 만들기와 초대 코드 |
| 12 | 크루 공개 | 세션 시작 화면에서 크루를 고르는 동작(없음, 하나, 여럿) |
| 13 | 문구 | "인증"이라는 말이 남아 있는가(기록 방식만 말해야 한다). 어색하거나 잘린 한국어 |
| 14 | 레이아웃 | 잘림, 겹침, 다크 모드, 작은 화면. 설정 버튼이 탭의 다른 버튼과 겹치는가 |
| 15 | 오류 | 로그의 오류와 크래시. `~/Library/Logs/DiagnosticReports`의 크래시 리포트 요약 |

### 3. 보고

스크린샷은 `~/Downloads/pondu-qa-report/`에 저장하고(이 폴더만 새로 만듭니다), 같은 폴더에 `REPORT.md`를 씁니다.

- **환경**: 기기, OS, 앱 번들 ID, 저장소 커밋과 미커밋 변경 유무, Xcode 버전
- **확인한 것**: 항목별 결과(통과, 실패, 확인 못 함)와 근거(스크린샷 파일명, 로그 한 줄)
- **발견한 문제**: 심각도(막힘, 큼, 작음) 순. 재현 방법, 코드를 읽어 원인이 보이면 파일과 줄
- **확인 못 한 것**과 그 이유

확인 수준은 `AGENTS.md` 3절의 표시를 씁니다. 시뮬레이터는 `[로컬]`, 연결된 실물 iPhone은 `[실기기]`입니다.
